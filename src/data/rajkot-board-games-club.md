## Overview

The Rajkot Board Games Club website is a dynamic community platform designed for event management, announcements, and maintaining a comprehensive game catalogue. 

## Key Features & Responsibilities

- **Community Hub**: Built a full-stack community site leveraging Next.js, React, and Supabase to effectively handle the club's event announcements and game catalogue.
- **Unique Design System**: Engineered an original 8-bit retro design system from scratch. Utilized custom design tokens and Styled Components to achieve a clean, consistent, and premium aesthetic that resonates with gamers.
- **Performance & SEO Optimization**: Implemented Static Site Generation (SSG) and dynamic route pre-rendering to maximize speed, ensuring excellent SEO and fast load times.
- **Robust Security & Safety**: Applied TypeScript extensively for comprehensive type safety across the frontend and backend operations. Integrated Supabase Row Level Security (RLS) to guarantee secure data access and user permissions.

## Technologies Used

- **Next.js / ReactJS**
- **TypeScript**
- **Supabase (PostgreSQL)**
- **Styled Components**
- **REST APIs**
- **Netlify**
