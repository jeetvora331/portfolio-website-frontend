## Overview

Zedo Designers is an architectural business portfolio designed as a production-grade, zero-cost web application. Leveraging a fully free-tier stack, it handles approximately 1K+ monthly users while maintaining a premium aesthetic and high performance.

## Key Features & Responsibilities

- **Zero-Cost Architecture**: Built the entire portfolio using a 100% free-tier stack, ensuring perpetual free hosting without sacrificing production quality.
- **Performance Optimization**: Optimized frontend performance through lazy loading, effective caching strategies, and category-based rendering. This significantly reduces unnecessary fetch calls, resulting in a snappy user experience.
- **Dynamic & Scalable Content**: Engineered a dynamic portfolio UI powered by spreadsheet-driven data for seamless content management.
- **Image Delivery via CDN**: Integrated Cloudinary CDN for efficient image delivery, scaling seamlessly with the heavy image requirements typical of an architectural portfolio.

## Technologies Used

- **ReactJS / Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Cloudinary**
- **Netlify**
